# 屏幕管控 · 初中英语单词锁屏后台

一个 Windows 桌面小程序：后台按设定周期（默认每 10 分钟）自动全屏弹出中文释义，
必须拼写正确的英文单词才能继续使用电脑，把「背单词」嵌进日常用电脑的节奏里。

- 词库：初中三年核心词汇 **2727 个**（七年级 915 / 八年级 914 / 九年级 898，含词性与年级标签）
- 弹窗：全屏遮罩 + 窗口置顶，显示中文释义与词性，输入正确英文后自动关闭
- 后台：家长密码保护，可调周期、范围、提示强度，查看统计与错词本
- 常驻：系统托盘图标常驻 + 开机静默自启，关窗口不掉管控
- 数据：全部本地存储（`data/` 目录），不联网、不上传任何内容

---

## 零、安装（推荐给普通使用者，不需要装 Python）

从 [Releases](https://github.com/110-hub/screen-guard/releases) 下载 **`屏幕管控安装程序.exe`**（约 29 MB，单文件安装器）。

1. 双击运行，点「开始安装」（会自动结束已运行的旧版本）。
2. 安装器会自动完成：解压到 `%LOCALAPPDATA%\Programs\ScreenGuard`、创建桌面与开始菜单
   快捷方式、加入开机静默启动、注册到 Windows「应用和功能」列表，然后启动程序。
3. 卸载：在 Windows 设置 →「应用」里卸载，或运行 `ScreenGuard.exe --uninstall`（需家长密码）。
4. 也可下载绿色包 `屏幕管控安装包.zip`，解压后双击 `安装.bat`（目录里的 `ScreenGuard/` 要一起保留）。

静默安装：`屏幕管控安装程序.exe --silent`。

安装版就是常驻形态：屏幕右下角托盘出现蓝色「A」图标。

| 托盘操作 | 效果 |
| --- | --- |
| 双击图标 | 打开家长端后台 |
| 右键 → 立即弹窗测试 | 马上弹一次题，用来验证是否生效 |
| 右键 → 暂停 30 分钟 | 临时不打扰（到点自动恢复） |
| 右键 → 恢复监控 | 取消暂停并重新计时 |
| 右键 → 退出（需密码） | 彻底退出程序 |
| 直接关闭后台窗口 | 只隐藏到托盘，管控继续生效 |

## 一、启动（源码方式，给开发者）

双击 **`run.bat`**（推荐，无黑色控制台窗口）。
也可以命令行运行：

```bash
pythonw main.py
```

首次启动会直接打开「屏幕管控后台 · 家长端」。
源码方式同样支持托盘常驻（需要 `pip install pystray pillow`，未安装时自动降级为普通窗口模式）。

> 环境要求：Windows + Python 3.8 以上（自带 tkinter 即可，无需安装任何第三方库）。

## 二、后台界面（家长端）

### 1. 管控设置

| 选项 | 说明 |
| --- | --- |
| 弹窗周期 | 每隔多少分钟弹一次窗，默认 10 分钟（1～180） |
| 每次答题词数 | 一次弹窗要连续答对的单词数，默认 1 个（1～5） |
| 答错几次给提示 | 答错时立即提示首字母与已拼对的开头，答错 N 次后显示完整「首字母 + 下划线」，0 = 不提示 |
| 家长跳过后暂停 | 家长用密码跳过本次后，暂停管控多少分钟 |
| 每日目标词数 | 今日进度条与统计的基准值 |
| 出题范围 | 全部词库 / 七年级 / 八年级 / 九年级 / 仅错词本 |
| 启用屏幕管控 | 总开关，关闭后不再自动弹窗 |

保存后立即生效，顶部会显示「管控中 / 已暂停 / 管控已关闭」和距下次弹窗的倒计时。

### 2. 词库

- 顶部显示总词数与各年级词数，支持按单词或中文释义搜索。
- 点「重新加载词库」可在修改词库文件后立即生效，无需重启。

### 3. 错词本

- 答错或跳过的单词自动进入错词本，答对一次错误次数减 1，减到 0 自动移出。
- 支持「移除选中」「清空错词本」「导出为 CSV」（导出到 `data/` 目录）。
- 出题范围选「仅错词本」时可专项复习。

### 4. 密码与安全

- 设置家长密码后：进入后台、跳过答题、退出程序都需要验证。
- 可勾选「开机自动启动屏幕管控」（写入系统启动文件夹，随时可取消）。
- 关闭后台窗口 = 退出程序（有密码时需要验证）。

## 三、答题弹窗怎么用

1. 到点后自动全屏弹出，卡片中央显示**中文释义**与词性（如 `n. 环境`）。
2. 在输入框里拼写英文，按 **Enter** 或点「提交答案」。
3. 答错：红字提示「不是正确答案」，同时立刻给出提示——首字母、已有开头拼对的字母、总字母数；
   达到设定的答错次数后显示完整的「首字母 + 下划线」提示。
4. 答对：绿色 ✔ 确认，约 0.8 秒后自动关闭，下个周期再弹。
5. 家长确实需要打断时，右下角「家长解锁跳过（需密码）」，验证后暂停管控一段时间。
6. 多显示器环境下，其它屏幕会被遮罩覆盖，避免绕开主屏去操作。

> 本项目按「中等管控」实现：**全屏置顶遮罩，不拦截 Alt+Tab 等系统快捷键**，
> 属于「提醒 + 强制答题」而非内核级锁屏，适合配合家庭约定使用。
> 若需要更强管控（拦截快捷键 / 禁止任务管理器），需要额外的键盘钩子与权限，可另行扩展。

### 自建 / 扩充词库

在 `data/words/` 下新建任意 `*.txt`（如 `words_06.txt`），每行一条，用竖线分隔四个字段：

```
word|pos|中文释义|grade
```

示例：

```
environment|n.|环境|9
look after|phr.|照顾|8
delicious|adj.|美味的；可口的|8
```

- `pos` 可选：`n. v. adj. adv. pron. prep. conj. num. art. modal phr. int.`
- `grade` 只能是 7 / 8 / 9
- 空行和 `#` 开头的行会被忽略；重复单词自动去重（保留首个）
- 保存后在后台点「重新加载词库」即可使用

## 五、常见问题

**Q：弹窗不出现？**
检查「启用屏幕管控」是否勾选并保存；顶部是否显示「已暂停」；是否点过「暂停 30 分钟」。

**Q：孩子直接关掉程序怎么办？**
设置家长密码后，退出、跳过答题都需要密码；也可开启「开机自动启动」。

**Q：词库太简单/太难？**
把「出题范围」切到某个年级，或先让孩子做一轮，之后用「仅错词本」专项复习。

**Q：想让电脑按周期提醒但不全屏？**
本项目按需求做成全屏遮罩；如需弱提醒可把 `quiz.py` 中 `attributes("-fullscreen", True)`
换成普通窗口尺寸。

**Q：数据会外传吗？**
不会。所有内容都在本机 `data/` 目录，纯离线运行。

## 六、打包与发布（开发者）

前提：装好打包依赖（只需一次）：

```bash
pip install pyinstaller pystray pillow
```

然后双击 **`打包.bat`**（或执行 `python tools\package.py`），它会依次：

1. `tools/make_icon.py` 生成 `assets/icon.ico`
2. PyInstaller 以 `--windowed` 生成 `dist/ScreenGuard/ScreenGuard.exe`（内置 `data/words` 词库）
3. 组装 `发布/屏幕管控安装包/`（`ScreenGuard/` + `安装.bat` + `卸载.bat` + `install.ps1` + 说明）
4. 压缩成 `发布/屏幕管控安装包.zip`

分发给别人时给 `屏幕管控安装包.zip` 即可，对方无需安装 Python。

### 安装器做了什么（install.ps1）

| 步骤 | 位置 / 说明 |
| --- | --- |
| 复制程序 | `%LOCALAPPDATA%\Programs\ScreenGuard`（覆盖升级时保留 `data/` 学习记录） |
| 快捷方式 | 桌面 + 开始菜单「屏幕管控」 |
| 开机自启 | 启动文件夹 `屏幕管控.lnk`，带 `--silent` 参数静默启动（只出托盘） |
| 卸载信息 | `HKCU\...\Uninstall\ScreenGuard`，显示在 Windows「应用和功能」 |
| 卸载 | `卸载.bat` 或「应用和功能」→ 结束进程、删快捷方式/自启/注册表/安装目录 |

### 常驻相关机制

- **单实例**：命名互斥体 `Global\ScreenGuard_EnglishWordLock_SingleInstance`，重复启动只提示一次，不会出现两个托盘图标。
- **托盘**：`tray.py` 用 pystray 起独立线程，菜单操作统一切回 Tk 主线程；无 pystray 时自动降级（关闭窗口=退出）。
- **静默自启**：`--silent` 参数启动时不展开后台窗口，只驻留托盘。
- **日志**：所有异常写入 `data\app.log`，打包后（无控制台）也便于排查。
